# Flexible Dodge

一个独立的 NeoForge 1.21.1 闪避模组。按键闪避（默认 **Left Alt**）向输入方向位移一小段距离，
并获得短暂的无敌帧：无敌帧内被命中（近战或**弹射物**）都会触发**完美闪避**，伤害完全取消。

## 玩法

- **闪避**：按 `Left Alt`（可在「选项 → 控制」中修改），方向由按下瞬间的移动键决定（八向），
  无移动键时默认向后。旁观模式与空中（非水中）不可闪避，水中可以。
- **无敌帧**：默认 0.2 秒。环境伤害（摔落、岩浆、溺水、仙人掌等）**不可躲避**，其余伤害均可。
- **完美闪避**：无敌帧内被命中 → 本次伤害被完全取消、**本次闪避取消冷却**（连闪计数照常累加），
  并播放专属音效与满条闪光。
- **弹射物**（箭、三叉戟、火球等）：无敌帧内玩家对弹射物**无碰撞箱**，弹射物**直接从身上穿过**——
  既不结算伤害，也**不会**触发原版 `AbstractArrow` 的反弹（`deflect(REVERSE)`），不减速、不消失、不插身，
  箭会继续飞向身后的目标。同时仍然**触发完美闪避**：服务端用与原版 `AbstractArrow.findHitEntity`
  完全相同的扫掠判定（同扫掠盒、同 0.3 容差，只是过滤器换成"只找该玩家"）补一次
  「若不过滤、原版会不会命中你」，命中即取消本次冷却并播放音效/闪光。
  自己射出的弹射物、以及 PvP 关闭/同队（原版 `canHarmPlayer` 判定不会命中你）的弹射物不算。
  已知边界：**面积型效果不受此保护**——溅射药水落在附近仍会给你效果、火球在身后炸开仍可能波及你
  （此时爆炸伤害若落在无敌帧内，仍会被拦截成完美闪避，但药水效果本身不会被抵消）；
  末影珍珠会直接穿过，不再把投掷者传送过来。

## 连闪冷却规则

| 闪避次序 | 位移结束后的冷却 |
|---|---|
| 第 1 次 | 无 |
| 第 2 次 | 0.1s |
| 第 3 次 | 0.2s |
| … | … |
| 第 7 次起 | 0.6s（上限） |

- 冷却**从「上一次闪避位移完全结束」的那一刻开始计算**。
- 距上一次闪避位移结束超过 **2 秒**没有再次闪避 → 连闪计数归零，冷却重新从第 1 次算起。
- 完美闪避**不重置**连闪计数，只是取消本次闪避的冷却。
- 无敌帧若配置得比闪避位移更长，会被压到与位移同时结束。

## 准星下方闪避冷却条

**自绘的半透明细长条**（16×4），位置在原版攻击冷却条正下方 2px。不使用原版的剑形进度贴图
（其左端 4px 是剑柄，低填充时会露出棕褐色一团），但沿用其配色（底槽 `#3A3B3C`、填充 `#D7D9EA`/`#FFFFFF`），
并采用与原版准星、攻击冷却条相同的**反相混合**（`ONE_MINUS_DST_COLOR` / `ONE_MINUS_SRC_COLOR`），
在任何明暗背景上都呈半透明可读。第一/第三人称都会绘制。

- **位移进行期间**：本次闪避冷却不为 0 → 显示**空条**；本次冷却为 0 → **不显示**。
- **位移结束后**：读条从空涨满，涨满（冷却结束）即隐藏。
- **完美闪避**：以**满条**状态整体闪一下后消失（默认 0.15s；前 40% 全亮再线性淡出，确保看得见）。

另有闪避指示标记：普通闪避 `< >` 向两侧淡出，完美闪避 `<<< >>>` 从内到外依次淡入淡出。

## 配置

服务端配置 `config/flexibledodge-server.toml`（加入服务器时由服务器同步）：

| 配置项 | 默认 | 说明 |
|---|---|---|
| `dodgeInvulnerabilityTime` | 0.2 | 无敌帧时长（秒），不超过闪避位移时长 |
| `dodgeSpeed` | 10.0 | 闪避峰值速度（格/秒） |
| `dodgeDistance` | 1.0 | 闪避距离（格）；与峰值速度共同决定位移时长（1.0 格 ⇒ 5 tick / 0.25s，实际滑行约 1.4 格） |
| `dodgeCooldownStep` | 0.1 | 连闪递增冷却步长（秒） |
| `dodgeCooldownMax` | 0.6 | 连闪冷却上限（秒） |
| `dodgeCooldownResetTime` | 2.0 | 连闪计数重置时间（秒） |

客户端配置 `config/flexibledodge-client.toml`（仅本机）：

| 配置项 | 默认 | 说明 |
|---|---|---|
| `dodgeMarkerEnabled` | true | 显示 `< >` / `<<< >>>` 闪避指示标记 |
| `dodgeMarkerTime` | 0.2 | 指示标记淡出时长（秒） |
| `dodgeCooldownBarEnabled` | true | 显示准星下方闪避冷却条（半透明；含完美闪避闪光） |
| `dodgeCooldownBarFlashTime` | 0.15 | 完美闪避满条闪光时长（秒） |

> 注意：配置文件里的值会被 NeoForge 保留。**升级模组后默认值不会自动写到已存在的配置文件**，
> 需要手动改写或删除 `run/config/flexibledodge-{server,client}.toml` 才会采用新默认值。

配置也可在游戏内「模组列表 → Flexible Dodge → 配置」界面修改。

## 给其它模组的事件

`com.lvyin3.flexibledodge.dodge.DodgeEvent`（闪避成功，携带玩家与方向）
与 `PerfectDodgeEvent`（完美闪避）在 `NeoForge.EVENT_BUS` 上派发。
